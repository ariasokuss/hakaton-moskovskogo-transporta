# Реестр внешних источников данных

Критерий 2а — **до 4 баллов**, по 1 за каждый использованный и подтверждённый эффектом
источник. **Источник без рабочей ссылки не засчитывается.**

Статус: `найден` → `подключён` → `подтверждён эффектом` (показали, что метрика улучшилась).

---

## 1. Погода — `найден`

**Open-Meteo** — бесплатно, без API-ключа для некоммерческого использования, глобальное
покрытие, реанализ ERA5 с 1940 года. Есть и исторические данные (для обучения), и прогноз
(для инференса) — редкое и важное сочетание: обучаемся и предсказываем на одном источнике.

- Historical Weather API: https://open-meteo.com/en/docs/historical-weather-api
- Основной сайт / Forecast API: https://open-meteo.com/
- Исходники: https://github.com/open-meteo/open-meteo

Поля под наши фичи: температура, осадки, ветер, снег.

## 2. Календарь и праздники — `найден`

**isDayOff** — производственный календарь РФ (рабочий/выходной/праздничный/сокращённый),
данные из официальных источников. API отвечает небыстро → **обязательно кэшировать**,
календарь меняется раз в год.

- API: https://www.isdayoff.ru/
- Обёртка и описание: https://github.com/KlukvaMors/isdayoff

Запасные варианты (статический JSON, быстрее и надёжнее для офлайн-сборки):
- https://github.com/d10xa/holidays-calendar
- https://github.com/iposho/holidays-calendar-ru
- https://calendar.kuzyak.in/

Плюс к этому сезонность и каникулы считаем сами из даты — отдельного источника не требуют.

## 3. Маршруты и остановки — `найден`

**Портал открытых данных Правительства Москвы (data.mos.ru)** — маршруты и остановки
наземного городского пассажирского транспорта. Нужен для геопривязки и для карты,
если в `dataset.zip` координаты окажутся неполными.

- Датасет: https://data.mos.ru/opendata/7704786030-marshruty-i-ostanovki-nazemnogo-gorodskogo-passajirskogo-transporta-marshruty
- Портал и API: https://data.mos.ru/
- Данные по работе Московского транспорта: https://transport.mos.ru/mostrans/for_journs/data

## 4. Дорожный трафик — `найден, есть сложность`

**Яндекс.Карты, балл пробок (0–10).**

⚠️ Практическое ограничение: балл пробок штатно достаётся через **JS API**
(`traffic.provider.Actual`, поле `state.get('level')`), то есть **на фронте, а не на бэке**.
Серверного HTTP-эндпоинта под балл пробок нет.

- traffic.provider.Actual: https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/ref/reference/traffic.provider.Actual
- Обсуждение способов получения балла: https://yandex.ru/blog/mapsapi/52230
- Router API (учитывает пробки при расчёте времени): https://yandex.ru/maps-api/products/router-api

Варианты для нас:
- **а)** снимать балл на фронте и отправлять на бэк как контекст — рабочий, но кривоватый;
- **б)** Router API: время проезда по участку маршрута против времени без пробок — прокси
  загруженности, считается на бэке;
- **в)** как **корректирующий коэффициент** в интерфейсе (критерий 2в) — честно и просто.

Для исторического обучения трафика за прошлые периоды у нас, скорее всего, не будет —
это надо явно написать в «области определения модели» (критерий 2б).

## 5. Ремонты и работы на путях — `подтверждён эффектом` ⭐

**Самый ценный источник из четырёх.** Не только даёт балл по критерию 2а, но и
закрывает главную неопределённость прогноза.

| | |
|---|---|
| Ссылка | https://newsvostok.ru/dlya-tramvaev-7-i-50-izmeneniya-po-vyhodnym-budut-dejstvovat-do-kontsa-oseni/ |
| Дополнительно | Telegram Дептранса https://t.me/s/DtRoad (парсер `parse_deptrans_tg.py` у ML-команды) |
| Что даёт | ремонт путей в Протопоповском переулке: маршрут 50 отменён по выходным полностью, маршрут 7 укорочен; будни в норме; срок «до конца осени» |

**Измеренный эффект:** отношение выходные/будни у маршрута 7 падает с 0.52–0.60
(янв–авг) до 0.34–0.35 (сен–окт), то есть −37%. У маршрута 50 выходные падают
с 9 000–14 000 до 8–2 736 посадок.

**Влияние на прогноз:** внутри окна ноябрь–декабрь режимы разные (ноябрь — работы
идут, декабрь — закончены). Цена ошибки ~1.5–2% Σy. Подробно — `data-anomalies.md`, раздел 0.

**Дата окончания найдена:** с 15.11.2025 движение по выходным восстановлено — https://t.me/DtOperativno/23565 (подробно — `data-anomalies.md`, раздел 0).

## 6. Строительство и открытие новых маршрутов — `найден, не оценён`

ТЗ прямо называет этот источник в нефункциональных требованиях: «Расширение за счет
внешних данных — прогнозов погоды, транспортной ситуации, **данных о строительстве
и открытии новых маршрутов**». Внутри прогнозного окна такие события есть:

| Дата | Событие | Ссылка |
|---|---|---|
| **12.11.2025** | запуск трамвайного диаметра **Т1** Метрогородок — «Университет» | https://t.me/DtRoad/54187 |
| **16–17.12.2025** | запуск маршрута **5** «Рижская — Белорусский вокзал» | https://t.me/DtRoad/55381 |
| **20.12.2025** | корректировка маршрутов; в справочнике `route_date_start = 2025-12-20` у маршрутов **7, 11, 12** | https://www.gazetametro.ru/articles/s-20-dekabrja-skorrektirujut-marshruty-nazemnogo-transporta-v-raznyh-chastjah-goroda-18-12-2025 |

**Почему это важно:** 7, 11 и 12 — наши целевые маршруты, они дают вместе около
90 тыс. посадок в сутки. Изменение трасс 20 декабря приходится на последние
12 дней прогнозного окна — это порядка 8% от Σy.

**Переосмысление справочника:** справочник организаторов датирован концом декабря
2025 — февралём 2026 (`actual_date`) и содержит `route_date_start = 2025-12-20`.
Это **не ошибочный срез**, а снимок сети на конец прогнозного периода. Вероятно,
это и есть подсказка организаторов про «открытие новых маршрутов».

Что остаётся необъяснённым: почему в справочнике нет маршрутов 17, 25, 26, 28, 50.

**Открытая задача:** выяснить, что именно изменилось у маршрутов 7, 11, 12
20.12.2025, и оценить эффект на последние 12 дней горизонта.
