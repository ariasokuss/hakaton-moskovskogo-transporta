# ML-часть: запуск, обучение, инференс

Прогноз `boardings(route, date, hour)` — число успешных валидаций на трамвайном маршруте за час —
на 01.11–31.12.2025 и в потоковом режиме (переобучение на данных «до сегодня»).

## Состав

| Файл | Что это |
|---|---|
| `baseline_colab.ipynb` | весь ML-контур: данные → пайплайн приёма → профиль → LightGBM → проверки → прогноз и артефакты |
| `tools/build_nb.py` | исходник ноутбука; `python tools/build_nb.py baseline_colab.ipynb` собирает его заново |
| `pipeline/ingest_raw.py` | приём сырых валидаций → почасовая витрина + сверка с labels (код вставляется в ноутбук при сборке) |
| `external_data/` | внешние данные и парсеры: календарь, погода, Telegram Дептранса (события, режимы, сбои, пробки) |
| `EXTERNAL_DATA.md`, `../../docs/external-sources.md` | ссылки и способы получения внешних данных |
| `../../docs/model-applicability.md` | область определения и адаптации модели |
| `../../docs/criteria-checklist.md` | чек-лист критериев ТЗ |

## Запуск (Google Colab, CPU достаточно)

1. Положите на Google Drive папку `MyDrive/mostrans/external_data/` (содержимое папки `external_data/` репозитория).
2. Откройте `baseline_colab.ipynb` в Colab → **Runtime → Run all**. Разрешите доступ к Drive.
3. Датасет организаторов скачивается автоматически с публичного Kaggle `shotme/moscow-transport` (ключ не нужен).

Время: ~25–35 минут на CPU (с `KAGGLE_FULL_DOWNLOAD=True` + пайплайн сырых данных ~45–60 минут).

### Параметры (первая ячейка)

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `KAGGLE_FULL_DOWNLOAD` | `False` | `True` — скачать сырые `train.csv`/`test.csv` (~10 ГБ) и прогнать пайплайн приёма со сверкой |
| `WEATHER_FOR_FORECAST` | `"fcst"` | архив прогнозов погоды (как в проде); `"fact"` — только для анализа, это утечка |
| `EVENTS_MODE` | `"all"` | `"all"` — новости, опубликованные и после отсечки (разрешено организаторами); `"strict"` — только до отсечки |
| `ORIGIN_STEP_DAYS` | `3` | шаг «точек прогноза» в истории для обучения LightGBM |
| `ML_MIN_WEIGHT` | `0.8` | минимальная доля ML в итоговом прогнозе (вес внутри диапазона — по CV) |
| `ML_ANCHOR_LEVEL` | `True` | суммарный уровень маршрута на горизонте — от профиля, распределение по дням и часам — от ML |
| `TRAFFIC_IN_MODEL` | `False` | поправка на пробки (в потоковой проверке прогноз ухудшает — выключена) |
| `USE_CHECKPOINTS` | `True` | сохранять долгие шаги и веса моделей на Drive и загружать их при повторном запуске |

## Модель

```
профиль (модель 1)   = уровень маршрута (3 недели) × форма суток (16 недель)
                       × календарь × режимы маршрутов × погода (≤ 7 дней) × сбои
LightGBM (модель 2)  = 9 бустеров: 3 горизонта обучения (цели на 1–3, 1–14, 1–28 дней) × 3 seed, ~90 точек прогноза истории,
                       цель — факт / профиль, вес — профиль (L1 ⇒ WAPE)
итог                 = (1 − w) · профиль + w · ML,   w ∈ {0.8, 0.9, 1.0} по CV
```

Прогноз прямой (direct) на весь горизонт, без рекурсии. Округление half-up — только при выгрузке.

## Чекпоинты (повторный запуск без переобучения)

Папка `MyDrive/mostrans/checkpoints/`:

| Что | Файл |
|---|---|
| подбор параметров профиля | `profile_grid_<ключ>.pkl` |
| прогноз на день вперёд для оценки погоды | `day_ahead_resid_<ключ>.pkl` |
| точки прогноза (признаки ~1.3 млн примеров) | `origin_frames_<ключ>.pkl` |
| замер эффекта внешних источников | `stream_1d_<ключ>.pkl` |
| веса каждой модели LightGBM (фолды, потоковый бэктест, финал) | `lgbm/lgbm_<ключ>.txt` |

Ключ — хеш кода ноутбука, данных и настроек (для моделей — хеш обучающей выборки, seed, параметров и версии LightGBM).
Изменили код, данные или параметр — нужный шаг пересчитается сам, устаревший чекпоинт не подхватится.
Повторный **Run all** с теми же настройками идёт в разы быстрее. `USE_CHECKPOINTS = False` — всё с нуля.
Тест на утечку на испорченных данных всегда пересчитывает признаки заново, поэтому чекпоинты его не обходят.

## Проверки внутри ноутбука

- **Тест на утечку**: данные после отсечки портятся/обрезаются — прогноз обязан совпасть бит в бит.
- **Потоковый бэктест**: сен–окт, еженедельное переобучение, горизонт 7 дней.
- **Эффект внешних источников** (критерий 2а): потоковый прогноз на день вперёд с отключением источников по одному; отдельно — погода на фев–окт.
- **5 хронологических фолдов** (горизонт 19–61 день), включая фолд с майскими праздниками.
