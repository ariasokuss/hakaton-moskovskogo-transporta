REST API прогноза пассажиропотока по сетке маршрут × дата × час. Прогноз предрассчитан ML-моделью; день, месяц, год и произвольный интервал — агрегация часов.

Эта страница — для людей. Программы на тех же адресах получают JSON (браузер просит Accept: text/html, остальные — нет).

Ошибки — RFC 9457, сообщения на русском, без стектрейсов. Попробуйте: неизвестный горизонт, дата вне прогноза.

Общие параметры прогноза

ПараметрЧто задаёт
routeномер маршрута (список — /api/routes); без него — все маршруты
stopостановка (список — /api/stops?route=): доля прогноза маршрута
horizonday — сутки по часам, month — месяц по дням, year — 12 месяцев
date / from, toдата горизонта или произвольный интервал
granularityhour · day · month — детализация интервала
kWeather, kEvent, kSeason, kTraffic, kManual корректирующие коэффициенты 0.3–3.0 (по умолчанию 1), применяются поверх прогноза модели
